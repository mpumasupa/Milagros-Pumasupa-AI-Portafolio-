# Featured Project

## AI-Powered Vehicle Damage Detection

This is my main Computer Vision project included in this portfolio.

### Overview

A deep learning-based system designed to automatically detect and classify vehicle damage from images. The goal is to support insurance and automotive industries by speeding up damage assessment processes.

### Key Features

* Image-based vehicle damage detection
* Deep learning model for classification
* Data preprocessing and augmentation
* Model evaluation and performance analysis
* Structured pipeline for real-world use cases

### Technologies Used

* Python
* PyTorch / TensorFlow
* OpenCV
* NumPy
* Jupyter Notebooks
