# AI Applications

This folder contains projects and assignments developed as part of the **AI Resource** course.  
It demonstrates practical applications of AI in research assistance and business optimization, covering data preprocessing, feature engineering, model experimentation, and prototype development.

---

## Contents

| Project | Description | Key Technologies |
|--------|-------------|-----------------|
| **[AI Research Agent](./AI-Research-Agent)** | Intelligent assistant that analyzes PDF and Word documents, generates structured research plans, and produces summaries. Collaborative project by the AI Applications course group. | Python, OpenAI API, Semantic Kernel |
| **[AI Inventory Optimizer](./AI-Inventory-Optimizer)** | Predictive system for inventory management. Forecasts weekly product demand, identifies trending products, and provides actionable insights. Includes baseline and advanced model experiments, MVP prototype, and detailed **Data Report** and **Evaluation Report** for analysis. | Python, Pandas, NumPy, scikit-learn, XGBoost, Google Colab |
