# AI Applications

This folder contains projects and assignments developed during the **AI Applications** course. It demonstrates practical applications of AI in research assistance and business optimization, covering data preprocessing, feature engineering, model experimentation, and prototype development.

## Contents

| Project | Description | Key Technologies |
|---------|-------------|-----------------|
| **AI Research Agent** | Intelligent assistant that analyzes PDF and Word documents, generates research plans, and produces structured summaries. Collaborative project by the AI Applications course group. | Python, OpenAI API, Semantic Kernel |
| **AI Inventory Optimizer** | Predictive system for inventory management. Forecasts weekly product demand, identifies trending products, and provides actionable insights. Includes baseline and advanced model experiments (Linear Regression, Random Forest, Gradient Boosting, XGBoost) and an MVP prototype. | Python, Pandas, scikit-learn, XGBoost, Google Colab |

## Tools Used

- Python  
- Google Colab  
- Pandas, NumPy, scikit-learn  
- XGBoost  
- Git and GitHub for version control
